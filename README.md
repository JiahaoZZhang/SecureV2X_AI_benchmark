# Analyze SYMAPS data with AI model

This project aims to analyze symaps data using AI model for misbehavior detection

## Project structure

- `dataset1/` : contient les données du site 1
- `dataset10/` : contient les données du site 10
- `rsu1.json` : contient des informations sur le point de fusion du site 1
- `rsu10.json` : contient des informations sur le point de fusion du site 10
